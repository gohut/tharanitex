5. GUIDELINES TO PREVENT FUTURE MERGE CONFLICTS
-----------------------------------------------
To avoid breaking the integration or getting into conflict hell during future git merges, follow these rules:

1. DO NOT DELETE OR REORGANIZATION FOLDERS WITHOUT COORDINATION:
   Keep all controllers, services, repositories and db utilities inside `frontend/src/` as mapped in this integration. Any renaming of `src/` to root directory will cause broken import paths across 100+ files.
   
2. ALIAS PATTERNS:
   Always use the `@/` path alias prefix to point to directories. It is mapped to `./src/*` inside `tsconfig.json`.
   Example:
   - Correct: `import Navbar from "@/components/home/Navbar/Navbar"`
   - Incorrect: `import Navbar from "../../components/home/Navbar/Navbar"`
   
3. PACKAGE MANAGEMENT:
   Before making commits on package.json, run `npm install` to keep `package-lock.json` aligned. Do not edit `package-lock.json` manually.

4. DATABASE SCHEMA MODIFICATIONS:
   If modifying SQLite database columns, do not change existing tables directly. Write migrations scripts inside `frontend/migrations/` and apply them to D1 database instances to avoid breaking production tables.
